Registration Guidelines

  • NGO must have valid government registration
  • Provide an active email for account verification
  • Logo should be at least 200×200 px
  • All fields marked with * are mandatory

After Registration

  • NGO receives login credentials via email
  • Profile becomes visible on the public portal
  • NGO can start receiving donor connections
  • Admin can deactivate at any time

Important Notice

Duplicate registrations are auto-detected. If an NGO with the same registration number exists, the form will flag it.
